koaEngine（自作エンジン）

目標：沖縄の海を自作ゲームエンジンで実装

制作人数
1人
SDK
DirectX12
制作期間
約1年半 // 現在も制作中
作品ページを見る→

||主な技術

  • 基本レンダリングPBR・Deferred + Forward
  • Gerstner Wave × FFT Ocean ハイブリッド水面
  • 物理ベース水面水の吸収・散乱から色を計算
  • 水面を光学境界面として扱う反射・屈折・コースティクス
  • 空の色を、大気の物理から計算するSky Atmosphere
  • 雲は、密度を積分して描いているVolumetric Cloud
